# ContactList
Lista de contatos simples feita em C.

## Instruções
Para compilar o Projeto execute `gcc *.c -o {Nome para o executável}.exe`, com compilador gcc (GNU).

## Uso
O sistema conta com armazenamento de dados em arquivo binário "contatos.bin", você pode executar o
código objeto quando compilado e seguir o fluxo de funções em ordem, ou preferencialmente, apenas
execute a ==primeira função== e sinta-se livre para explorar o sistema.

### Secret
Para excluir completamente a base de dados e recomeçar uma nova lista de contatos, você pode selecionar
'8' no menu inicial, existe uma case não exibida no terminal para limpar o arquivo binário que contém os dados
sinta-se a vontade para testar.
